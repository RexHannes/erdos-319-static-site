Part 1

Problem And Notation

Erdős Problem #319 is treated here as a signed reciprocal circuit problem. For a finite set X, write R(X) = sum_{x in X} 1/x. A signed set is split into two disjoint sides P and Q, with the balance condition R(P) = R(Q).

The formalization keeps the elementary combinatorial core separate from analytic number-theory inputs such as Croot, Bloom, and Liu-Sawhney style unit-fraction theorems. 

def R (X : Finset Nat) : Rat :=
  X.sum (fun n => if h : n = 0 then 0 else (1 : Rat) / (n : Rat))
Part 2

Primitive Circuits

A circuit is primitive when it has no non-empty proper signed zero-subcircuit. In Lean-facing terms, that means there are no proper subsets P' subset P and Q' subset Q with equal reciprocal sums, except for the empty collision and the full collision.

This is the first clean part of the programme: it is elementary, precise, and does not require analytic black boxes. 

structure Circuit where
  P : Finset Nat
  Q : Finset Nat
  disjoint : Disjoint P Q
  positiveP : forall n in P, 0 < n
  positiveQ : forall n in Q, 0 < n
  balanced : R P = R Q

Spectrum Criterion
